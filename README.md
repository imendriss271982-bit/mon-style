# Mon style

Application de personal styling : analyse du visage, colorimétrie (12 saisons), morphologie, type Kibbe, outfit check, boutique et styliste vocale.

## Fichiers

- `index.html` : toute l'application (une seule page).

## Mettre en ligne gratuitement avec GitHub Pages

1. Sur GitHub, ouvre ce dépôt, puis **Settings → Pages**.
2. Dans *Source*, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`.
3. Enregistre. Après une minute, l'application est en ligne à l'adresse `https://<ton-nom>.github.io/mon-style/`.

## Note

L'analyse des photos et le chat écrit utilisent les fonctions de Claude : elles marchent dans la version publiée sur claude.ai. Sur GitHub Pages, le questionnaire de couleurs, la boutique, la voix et l'appel à la styliste (ElevenLabs) fonctionnent ; l'analyse par photo demandera un service d'IA branché séparément.
